# Smart City Management System

A Python-based Smart City Management System developed using Object-Oriented Programming (OOP) concepts. This project simulates the management of different city services such as traffic, parking, healthcare, police, fire department, utilities, complaints, and citizen records through a menu-driven console application.

## Features

- Citizen Management
- Employee & Admin Management
- City and Zone Management
- Department Management
- Vehicle Management
  - Car
  - Bike
  - Bus
- Traffic Monitoring
- Traffic Signal Management
- Parking Management
- Parking Slot Allocation
- Hospital Management
- Ambulance Management
- Police Station & Police Vehicle Management
- Fire Station & Fire Truck Management
- Electricity Management
- Water Supply Management
- Garbage Collection Management
- Complaint Registration
- Notification System
- Report Generation

## Technologies Used

- Python 3
- Object-Oriented Programming (OOP)
- Modules and Packages
- Exception Handling
- Functions
- Classes & Objects

1. Clone the repository

```bash
git clone 
```

2. Navigate to the project folder

```bash
cd Smart-City-Management-System
```

3. Run the application

```bash
python main.py
```
